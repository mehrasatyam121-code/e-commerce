# Ecommerce Sales Dashboard

## Project Overview
This Power BI dashboard analyzes ecommerce sales performance, customer behavior, profit trends, and delivery insights.

## Tools Used
- Power BI
- SQL

## Dashboard Features
- Monthly Sales Analysis
- Category-wise Revenue
- Top Selling Products
- Customer Insights
- Profit Trends
- Regional Performance

## Key Insights
- Identified top-performing categories
- Analyzed customer purchasing behavior
- Tracked sales growth trends
- Found high-profit regions
